States ​

Radio supports default, hover, focus, error, selected, and disabled states. Use the error attribute when a radio needs error styling. Hover or focus the enabled radios below to see their interactive states.

Default
Error
Disabled
vue
<template>
  <div class="radio-states">
    <div class="radio-state">
      <span>Default</span>
      <el-radio v-model="defaultValue" value="selected">Selected</el-radio>
      <el-radio v-model="defaultValue" value="other">Unselected</el-radio>
    </div>
    <div class="radio-state">
      <span>Error</span>
      <el-radio v-model="errorValue" value="selected" error>Selected</el-radio>
      <el-radio v-model="errorValue" value="other" error>Unselected</el-radio>
    </div>
    <div class="radio-state">
      <span>Disabled</span>
      <el-radio v-model="disabledValue" value="selected" disabled>
        Selected
      </el-radio>
      <el-radio v-model="disabledValue" value="other" disabled>
        Unselected
      </el-radio>
    </div>
  </div>
</template>

const errorValue = ref('selected')
const disabledValue = ref('selected')

Radio groups with feedback ​

Radio and RadioGroup automatically follow the error state of their containing FormItem. You can also set error manually to apply the state without form validation. Feedback banners remain separate from the group, so their severity can be changed independently. A warning banner does not change the radio controls themselves.

Error message
Warning message
vue
<template>
  <div class="feedback-groups">
    <div class="feedback-group">
      <el-alert
        title="Error message"
        type="error"
        :closable="false"
        show-icon
      />
      <el-radio-group v-model="errorValue" error class="vertical-group">
        <el-radio v-for="option in options" :key="option" :value="option">
          {{ option }}
        </el-radio>
      </el-radio-group>
    </div>
    <div class="feedback-group">
      <el-alert
        title="Warning message"
        type="warning"
        :closable="false"
        show-icon
      />
      <el-radio-group v-model="warningValue" class="vertical-group">
        <el-radio v-for="option in options" :key="option" :value="option">
          {{ option }}
        </el-radio>
      </el-radio-group>
    </div>
  </div>
</template>

<script lang="ts" setup>
import { ref } from 'vue'

const options = ['Option 1', 'Option 2', 'Option 3', 'Option 4']
const errorValue = ref('Option 2')
const warningValue = ref('')
</script>

<style scoped>
.feedback-groups {
  display: flex;
  flex-wrap: wrap;
  gap: 40px;
}

.feedback-group {
  display: grid;
  width: 240px;
  gap: 12px;
}

.vertical-group {
  display: flex;
  align-items: flex-start;
  flex-direction: column;
  gap: 12px;
}

.vertical-group .el-radio {
  margin-right: 0;
}
</style>
